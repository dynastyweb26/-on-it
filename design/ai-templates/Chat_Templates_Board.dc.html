On It · Board 9 · Chat assistant templates
Nine templates the assistant fills.
Each template is a slot contract, not an answer. Designed at 390 (template column 322 next to the 28px avatar), then shown in the 720 chat column at 1280. Every template has loading, empty, error and filled states plus long-content behavior.
+$ In green, always signed
−$ Out red, always signed
Gold is fill only. Gold text uses #7A5E00
boltMotion only on Sent, Saved, Requested
paymentsBubbles never show $. Templates do

T5
Draft message
A message the assistant wrote for the user to send. Built like Record this payment: header tile, dashed rows, then actions.
recipientName · phone? · email?
channel: Text|Email · device: phone|laptop
aboutLabel? · aboutAmount?
body: string (editable)
onSend · onOpenMessages · onCopy · onMarkDone
onEdit · onCancel · onAddContact
• The About row puts the amount in a slot, so the bubble above never needs it.
• Editing uses the gold focus ring from the Amount field.
• Text hands off to the phone's Messages app, so On It can't know if it was sent. Primary is Open in Messages; after the tap the card says Opened, with Reopen and Mark done.
• Text's only error is "couldn't open Messages", with Copy text as the fallback.
• At 1280 (device: laptop) Text's primary is Copy text.
• The check pops in only on Email Sent or Text Mark done. With reduced motion it just appears.
• Cancel collapses the card to one line with Undo.
• Long bodies grow the card. Long names truncate in To.

Batch confirm
Two to four actions, one approval. For "Ruth paid, remind Tony, log the Home Depot run."

  tone in|out|neutral, status?
onRemove(id) · onConfirmAll()
onRetry(ids) · onUndoAll()
• Each row is one line. The summary truncates; the amount never does.
• Remove has a 44px target. Removing every row shows "Nothing left to confirm" with Bring back.

• Partly failed shows Saved or Didn't save on every row, each with an icon and a word. Retry sends only the failed rows.
• Try 6.2: Confirm all saves after 1.1s. 6.6 fails one row.

T9
Feedback
Quiet thumbs, an inline follow-up on thumbs-down, and an occasional check-in card.
Feedback: responseId, vote null|up|down
  onVote(vote, reasons[], note)
CheckIn: onPick(choice), onDismiss()
  moreHref → Help & feedback
• Thumbs sit 4px under the latest response, left-aligned with it. One set per response, even when it includes a card.
• They fade in (opacity, 150ms) only after the text has finished. A new response removes them from the previous one.
• Up: the icon fills. No popup, no thank-you.
• Down: the icon fills and the follow-up opens inline under it (PopInline pattern). Close, Skip and Send all keep the thumbs-down.
• Loading and empty don't apply. Error means the follow-up didn't send.
• Check-in: dismiss removes it and the chat reflows.

Templates in a real chat
T1, T2, T5 and T9 together. This sets the spacing between bubbles and templates.
side padding ........ 16
avatar 28 + gutter .. 8
date label ↔ turn ... 20
between turns ....... 24
user → reply ........ 16
bubble → template ... 8
template → thumbs ... 4
thumbs offset ....... −10 (optical)
• The bubble names the subject and never shows an amount. The template carries the numbers.
• A reply with a template has one avatar, at the top of the reply.
• Thumbs appear only under the latest reply.
