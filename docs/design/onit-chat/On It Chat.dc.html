leaving elements · no bounce, no spring overshoot
Rules. Only transform and opacity animate. Height changes use Framer layout, which is transform-based. The CSS prototype uses grid-template-rows as a stand-in. Animations never block input: no pointer-events:none on live controls and no awaiting animations before state changes. Loops (dots, caret, mic rings, spinner) are CSS keyframes. Reduced motion: every entry becomes opacity-only at 160ms, the typewriter is instant with no caret, and there's no sweep, no shared-element travel and no ring pulse.
